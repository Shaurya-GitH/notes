A collection of software that manages a computer's hardware and applications by allocating resources, including memory, CPU, input/output devices and file storage.

- **Shell** : User interface that allows users to request specific tasks from the computer
- **Kernel** : Communicates between hardware and software of a computer
- **Secure Shell (SSH)** : Establishes a secure remote CLI connection to a device, through a virtual interface, over a network.
- **Telnet** : Insecure remote CLI connection (plain text)
- **Bootloader** : A small program that initializes and loads an operating system into a computer's memory during the startup process
- **Process** : Program in execution

The Bootloader starts the process of booting, it locates and loads the operating system's kernel and other necessary files, and then hands control over to the operating system.
