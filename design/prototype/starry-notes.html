Who I Am

I'm a full-stack engineer who enjoys hard problems more than any single technology. I like understanding a system end to end, finding the bottleneck, and building something that makes a measurable difference. These days that covers four things: I do AI, I do full stack, I do DevOps, and I do security.

  • Porter AI. A voice-and-text shopping agent wired into a live storefront. It calls server tools for product, variant, warranty and shipping data, and client-side actions that reveal page sections and navigate shoppers.
  • Alfred-OS. A voice-controlled macOS agent that routes commands to browser and desktop agents, runs them as background tasks, and asks for spoken confirmation before anything destructive.
  • Office AI memory. A memory system for coding agents that I built on SQLite and serve over MCP. Every write runs its own checks, and conflicting edits are refused, so each fact has one owner.
  • Faster agents. I cut voice-agent reply latency by about 45% on real traffic by moving the backend next to the services it calls, then added tool caching and fixed truncated tool calls.
